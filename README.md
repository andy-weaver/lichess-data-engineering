# lichess-data-engineering
A medium/large scale data engineering project. A full data pipeline that starts with raw PGN files of lichess games and ends with a chess-playing bot that closely mimics human actions, at any rating level.

## Objectives
1. Build a scalable data pipeline that can handle large amounts of raw and relatively unstructured data.
2. Demonstrate various common technologies and tools used in data engineering/feature engineering.
   1. Languages: Python, SQL, Spark, Rust, Shell scripting
   2. Tools: AWS, Docker, Kubernetes, Airflow, Jenkins
   3. Databases: PostgreSQL, Redis, Elasticsearch
   4. Data formats: Parquet, PGN (Portable Game Notation - text-based format for chess games)
3. Demonstrate proficiency in AWS services, particularly S3, Glue, and Lambda.
4. Train a neural network to play chess using the data generated by the pipeline, focusing not on optimal play but on human-like play at various rating levels.
   1. Demonstrates proficiency in PyTorch. 
   2. Demonstrates proficiency in feature engineering for neural networks, as well as neural network architecture design.
5. Build a chess-playing bot that can play on lichess.org and mimic human actions at any rating level.
   1. The goal is not to build a bot that plays optimally, but to build a bot that plays like a human
   2. Potential use cases include:
      1. Training tool for chess players
      2. Benchmarking tool for chess engines
      3. Educational tool for chess enthusiasts who want to try out different strategies and see how they fare against human-like play. (Right now playing against a chess engine is the only option, and it's not very human-like.)

## Steps (Overview)
1. **Data Collection**: Download raw PGN files from lichess.org.
2. **Data Processing**: Parse PGN files and store them in a database.
3. **Feature Engineering**: Extract features from the data and store them in a database.
4. **Model Training**: Train a neural network to play chess using the features.
5. **Bot Development**: Develop a chess-playing bot that can play on lichess.org.
6. **App Development**: Develop a web app that allows users to play against the bot.

```python
# pgn_parser.py

import re
from typing import Dict, List, Optional

class PGNParser:
    """
    A parser for PGN files to extract game metadata and moves.

    Attributes
    ----------
    header_pattern : re.Pattern
        Compiled regular expression to capture PGN header key-value pairs.
    """

    def __init__(self):
        self.header_pattern = re.compile(r'\[(\w+)\s+"([^"]+)"\]')

    def parse_headers(self, pgn_text: str) -> Dict[str, str]:
        """
        Parse the headers from a PGN text block.

        Parameters
        ----------
        pgn_text : str
            The raw PGN text containing header information.

        Returns
        -------
        dict
            A dictionary with header keys and their corresponding values.
        """
        headers = dict(self.header_pattern.findall(pgn_text))
        return headers

    def parse_moves(self, pgn_text: str) -> List[str]:
        """
        Extract move sequences from PGN text.

        Parameters
        ----------
        pgn_text : str
            The raw PGN text including move sequences.

        Returns
        -------
        list of str
            A list of moves in the game.
        """
        # Remove headers
        moves_section = re.split(r'\n\n', pgn_text, maxsplit=1)[-1]
        # Remove move numbers and result annotations (e.g., 1-0, 0-1, 1/2-1/2)
        moves = re.sub(r'\d+\.', '', moves_section).strip()
        moves = re.sub(r'(1-0|0-1|1/2-1/2)', '', moves).strip()
        # Split on whitespace
        return moves.split()

    def parse(self, pgn_text: str) -> Optional[Dict[str, any]]:
        """
        Parse a full PGN file text block.

        Parameters
        ----------
        pgn_text : str
            The full PGN text for a single game.

        Returns
        -------
        dict or None
            A dictionary with 'headers' and 'moves' keys if parsing is successful,
            or None if the input is empty.
        """
        if not pgn_text.strip():
            return None

        return {
            "headers": self.parse_headers(pgn_text),
            "moves": self.parse_moves(pgn_text)
        }
```

import pytest
from pgn_parser import PGNParser

@pytest.fixture
def sample_pgn():
    return (
        '[Event "Live Chess"]\n'
        '[Site "https://lichess.org/abc123"]\n'
        '[Date "2025.01.01"]\n'
        '[White "PlayerA"]\n'
        '[Black "PlayerB"]\n'
        '[Result "1-0"]\n\n'
        '1. e4 e5 2. Nf3 Nc6 3. Bb5 a6 4. Ba4 Nf6 5. O-O Be7 1-0'
    )

def test_parse_headers(sample_pgn):
    parser = PGNParser()
    headers = parser.parse_headers(sample_pgn)
    assert headers["Event"] == "Live Chess"
    assert headers["Site"] == "https://lichess.org/abc123"
    assert headers["Date"] == "2025.01.01"
    assert headers["White"] == "PlayerA"
    assert headers["Black"] == "PlayerB"
    assert headers["Result"] == "1-0"

def test_parse_moves(sample_pgn):
    parser = PGNParser()
    moves = parser.parse_moves(sample_pgn)
    # Expect moves without move numbers and result
    expected_moves = ['e4', 'e5', 'Nf3', 'Nc6', 'Bb5', 'a6', 'Ba4', 'Nf6', 'O-O', 'Be7']
    assert moves == expected_moves

def test_parse_full(sample_pgn):
    parser = PGNParser()
    game_data = parser.parse(sample_pgn)
    assert "headers" in game_data
    assert "moves" in game_data
    assert game_data["headers"]["White"] == "PlayerA"
    assert len(game_data["moves"]) == 10

if __name__ == "__main__":
    pytest.main([__file__])
